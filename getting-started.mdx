## Setting Up Your Account

Welcome to UltraStudio AI Documentation! This guide will walk you through the initial setup process to get your documentation space configured and ready for content.

<Steps>
  <Step title="Create Account" icon="user-plus">
    Sign up for an UltraStudio AI account using your email or integrate with GitHub/GitLab for seamless authentication.
    
    <CodeGroup tabs="Email, GitHub">
      ```javascript
// For email signup, use our API
const signup = await fetch('/api/auth/signup', {
  method: 'POST',
  body: JSON.stringify({
    email: 'user@example.com',
    password: 'securePassword123'
  })
});
      ```
      ```javascript
// GitHub OAuth integration
const githubAuth = await fetch('/api/auth/github', {
  method: 'GET'
});
      ```
    </CodeGroup>
  </Step>
  <Step title="Choose Your Plan" icon="credit-card">
    Select from our free starter plan or upgrade to pro/enterprise for advanced features like team collaboration and custom domains.
  </Step>
  <Step title="Configure Workspace" icon="settings">
    Set up your workspace name, default theme, and basic navigation structure.
  </Step>
  <Step title="Import Content" icon="upload">
    Upload your existing documentation files or connect your repository for automatic syncing.
  </Step>
</Steps>
